One filter, all lights

The other way round: pick one filter or pigment and see which lights in the library change it the least, or the most. Uses the lights and settings chosen in LED compare (see the strip above).

“Each light’s own ideal reference” compares the filter under every light with the same filter under a perfectly rendering light of the same colour temperature, so the ranking shows which lights show this filter most faithfully. With “light A” the ranking shows which lights are closest to (or furthest from) A. Click a column heading to sort by it, and click a light’s name to open it in the LED library. Colour dots show the colour the filter has under each light (left: reference, right: that light); in the brightness view they are darkened by how much light gets through.
